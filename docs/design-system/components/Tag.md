# Tag

Etiqueta de una palabra para marcar un atributo (Principal, OCR, PDF, abreviatura de provincia) y contador numérico.

Texto mínimo 11px, peso 600, sobre `surface-raised`, `accent-soft` o `success-soft`. No usar texto blanco sobre relleno `accent` o `success`: no alcanza contraste. El contador (`gv-count`) usa cifras tabulares.

En Flutter: `AppTag` y `CountBadge`. Reemplaza los badges con radios 4/6/8/12/20 y los textos de 8–10px.
