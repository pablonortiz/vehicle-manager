# SegmentedControl

Selector de una opción entre 2 a 4, todas visibles.

Contenedor `surface-raised`; la opción activa pasa a `surface` con contorno `border-strong` y texto `text`. Usar para período, orden y alcance de exportación. Con 5 o más opciones usar un campo desplegable.

El consumidor provee las opciones y la selección.

En Flutter: `SegmentedButton` estilizado. Reemplaza los selectores hechos con `GestureDetector` en `pdf_export.dart` y `_ScopeOption`.
