# AppDropdownField

Campo desplegable con el mismo label, alto y bordes que `TextField`.

Usar con 5 o más opciones, o cuando la lista es dinámica (provincia, combustible). Con 2 a 4 opciones fijas usar `SegmentedControl`. Obligatorio se marca con " *" en el label.

El consumidor provee label, valor inicial, opciones, `onChanged` e ícono opcional.

En Flutter: `AppDropdownField` (`lib/presentation/widgets/app_dropdown_field.dart`).
